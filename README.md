# move_lrc_to_audio

交互式工具：根据 `.lrc` 文件名（不含后缀）在指定目录中查找同名音频，并将 `.lrc` **复制**到音频所在文件夹（**不删除、不移动**源文件）。

## 要求

- Node.js 18+（仅内置模块）

## 运行

```powershell
node move_lrc_to_audio.js
```

启动后按步骤输入，无默认路径：

| 步骤 | 说明 |
|------|------|
| 1 | 输入一个或多个 **LRC 源文件夹** |
| 2 | 输入一个或多个 **音频搜索目标文件夹**（递归子目录） |
| 3 | 自动预览（不复制） |
| 4 | 确认后执行复制 |
| 5 | 执行复制 |

## 示例

```
【步骤 1】LRC 源...
> G:\lrc
是否再添加一个 LRC 源文件夹 (y/n): y
> D:\backup\lrc

【步骤 2】搜索目标...
> G:\喜欢
是否再添加一个搜索目标文件夹 (y/n): y
> G:\深情

【步骤 4】是否复制... (y/n): y
```

## 规则

- **复制**到音频旁，LRC 源目录中的文件保留
- 匹配：`歌曲.lrc` ↔ `歌曲.flac` / `歌曲.mp3`（忽略大小写）
- 扫描音频时跳过所有 LRC 源目录
- 目标已有同名 `.lrc` → `[已存在]`，跳过
- 同名音频在多个不同文件夹 → `[重名冲突]`，跳过
