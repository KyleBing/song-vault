<h1 align="center">乐库管理</h1>

<p align="center">
桌面应用：歌词归位、音频库管理与双乐库同步，管理本地音频文件。
</p>

## 一、功能概览

| 序号 | 工作台 | 说明 |
|------|--------|------|
| 1 | LRC 歌词归位 | 从 LRC 源文件夹扫描歌词，复制到音频搜索目标中同名音频所在目录；支持预览匹配、批量复制与多余歌词清理 |
| 2 | 音频库 | 浏览本地音频目录树，查看元数据与封面，支持搜索、Shift 多选、移动与删除 |
| 3 | 乐库同步 | 对比左右两个乐库目录的音频差异（相同、仅一侧、大小不同、已移动），支持跨库复制与同库内移动对齐路径 |
| 4 | 设置 | LRC 源、音频目标、乐库目录、路径过滤规则等配置 |

## 二、环境要求

1. Node.js 18+
2. Yarn 1.x（见 `packageManager` 字段）

## 五、打包客户端

先执行 `yarn install`，再在本机平台打包（产物位于 `release/`）：

```bash
# macOS → .dmg
yarn pack:mac

# Windows → 安装包（建议在 Windows 上执行）
yarn pack:win
```

`pack:mac` / `pack:win` 通过项目 `.npmrc` 中的 npmmirror 镜像下载 Electron 与 electron-builder 二进制，Windows / macOS 均可直接运行。若需从 GitHub 官方源下载，可使用 `pack:*:original`（会临时忽略镜像配置）。

## 六、LRC 歌词归位 — 使用流程

1. 在 **设置** 中添加一个或多个 **LRC 源文件夹**（递归扫描子目录中的 `.lrc`）
2. 添加一个或多个 **音频搜索目标**（递归子目录）
3. 点击 **预览匹配** 查看结果（以音频为主的多个标签页）
4. 确认后点击 **执行复制**（源文件夹中的 `.lrc` 保留，不移动）
5. 在 **多余歌词** 标签中可勾选并删除目标目录内无同级同名音频的 `.lrc`

### 6.1 结果标签页

| 序号 | 标签 | 内容 |
|------|------|------|
| 1 | 全部音频 | 目标文件夹内所有音频及匹配状态 |
| 2 | 已匹配 | 本目录已有同级同名歌词与音频 |
| 3 | 待复制 | 可从 LRC 源复制到本目录 |
| 4 | 缺歌词 | 本目录无歌词且源中无或存在多个同名 |
| 5 | 多余歌词 | 目标内无配对音频的歌词，支持删除 |

### 6.2 匹配规则

1. 复制到音频旁，不删除、不移动源文件
2. 按文件名（不含后缀）匹配，忽略大小写
3. 扫描音频时跳过所有 LRC 源目录
4. **已匹配**：目标文件夹**同级目录**下，同时存在主文件名相同的 `.lrc` 与音频
5. 同名音频分布在多个不同文件夹时视为重名冲突，跳过

## 七、乐库同步 — 简要说明

1. 在 **设置 → 同步设置** 中指定左右乐库根目录（可设置显示别名）
2. 打开 **乐库同步** 工作台，点击 **扫描对比**
3. 在差异树中查看统计与明细；**已移动** 表示两侧均有同名同大小音频但相对路径不同
4. 操作方式：
   1. 仅一侧有文件：箭头指向的一侧从另一侧**复制**缺失文件
   2. 已移动：在箭头指向的乐库内**移动**（rename）文件以对齐另一侧路径，同名 `.lrc` 会一并移动
5. 支持 Shift 连选与批量同步
